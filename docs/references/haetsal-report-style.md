# 햇살의원 평가보고서 스타일 가이드

> AI 평가보고서 생성 시 이 가이드를 system prompt에 포함시켜 일관된 양식·문장 스타일을 유지한다.
> 원본 샘플 PDF는 `.local-reports/sample-reports/` (로컬 전용, .gitignore 처리됨 — 환자 개인정보 포함)에 보관.
> ⚠️ 원본 PDF에는 실명·생년월일·주소·연락처가 들어있어 **GitHub에 절대 푸시 금지**.

## 1. 보고서 종류와 사용 도구

| 보고서 종류 | 평가자 직책 | 표제 | 사용 검사도구 (대표) |
|---|---|---|---|
| 말·언어 평가보고서 | 언어재활사 1급 | `햇살의원 아동발달클리닉 / 말ㆍ언어 평가보고서` | SELSI, K M-B CDI, PRES, REVT, U-TAP, KOLRA, LSSC |
| 감각통합 평가보고서 | 작업치료사 | `햇살의원 아동발달클리닉 / 감각통합 평가보고서` | K-TSP2 (만3세 미만) / K-CSP2 (만3세 이상), K-DDST2, K-DST |
| 중간 평가보고서 | 담당 재활사 | `중간 평가보고서` (영문 양식 헤더) | 기존 검사 + 비교 |

## 2. 문서 구조 (말·언어 평가보고서)

```
[헤더 표] 이름/성별 · 평가자 · 생년월일(연령) · 평가일 · 주소 · 정보제공자 · 연락처

I.   배경정보       (산모연령·재태기간·출산방식·발달력·양육환경·주호소)
II.  검사태도       (분리·낯가림·주된 의사표현 수단·eye contact·놀이패턴)
III. 실시한 검사    (도구명 1, 2, 3 — 번호 매김)
IV.  검사결과
     1. 말·언어 능력
        가. 언어    → 각 표준화검사 결과 표 + 1-1) 1-2) 1-3) 식의 항목별 해석
        나. 조음    → U-TAP 결과 표 + 오류양상
V.   요약 및 결론   (각 검사 재요약 → "> 검사 결과, 아동은 ○○○으로 판단됨." → 권고)

[푸터] 평가자 언어재활사 1급 제 ○○○○호 ○ ○ ○
```

## 3. 문서 구조 (감각통합 평가보고서)

```
I.   배경정보
II.  검사태도
III. 실시한 검사 (K-TSP2 또는 K-CSP2 / K-DDST2 / K-DST)
IV.  검사결과
     1. K-TSP2(or K-CSP2)  → 사분면 표 + 감각섹션 표 (+ K-CSP2는 행동섹션 표 추가)
     2. K-DDST2            → 영역×항목×결과(Pass/Fail)×결과해석 표
     3. K-DST              → 영역×총점×평가결과 표 + 추가질문
V.   요약 및 결론           (한 단락으로 검사별 요약)
VII. 제언                  (※ VI 없음, V → VII로 점프 — 원본 양식 그대로)

[푸터] 작업치료사 ○ ○ ○
```

## 4. 문서 구조 (중간 평가보고서)

```
[헤더] Name / DOB / Date / Gender / Chronological age / 검사자 / Informer (영문 라벨)

Ⅰ. Test Attitude
Ⅱ. Test Findings
   1. Language Test
      (1) Standardized test
          1. [도구명]  → 결과 표
          2. [도구명]  → 결과 표
Ⅲ. Test Summary & Recommendations
   - 검사별 결과 재요약
   - 이전 검사와의 비교 (`> 23.10.13.(2;10) ... ➔ 전반적인 언어 수준이 증진됨.`)
   - "- 검사 결과 아동은 ○○○으로 판단됨." 식 결론
   - "- 전반적인 ○○○ 향상을 위한 주 N회 언어재활이 도움 될 것으로 판단됨."

[푸터] 언어재활사 1급 제 ○○○○호 ○ ○ ○
```

## 5. 종결어미·문체 규칙 ★중요

- **모든 서술형 문장은 `~음/~었음/~함/~였음`으로 종결.** ("~다", "~합니다" 절대 사용 금지)
  - 예: "보호자와 분리가 가능하였**음**", "낯가림이 없는 편이**었음**", "주호소로 본 기관에 내원하**였음**", "어려움이 있다고 보고하**였음**"
- **결과 서술은 "~로 평가됨", "~로 판단됨", "~로 나타남"** 형태.
  - 예: "백분위수 <1%ile로 평가됨", "언어발달지체로 평가되었음", "약 1M delayed 된 것으로 평가됨"
- **권고 종결은 "~필요할 것으로 판단됨" / "~도움이 될 것으로 판단됨" / "~권고됨".**
- **요약 항목은 `>` 또는 `-` bullet으로 시작.** 중첩 항목은 들여쓰기 + `>`.

## 6. 자주 쓰는 표현 사전

### 배경정보 표현
- `본 대상자는 [주호소]를 주호소로 본 기관에 내원하였음.`
- `보호자의 보고에 의하면 산모연령 [N]세에 [재태기간], [n번째] baby, NC/SD로 출산하였다고 함.`
- `신체 발달력으로는 [내용]이라고 함.`
- `언어발달력을 살펴보면, [내용]이라고 함.`
- `현재 [어린이집/유치원/초등학교 N학년]에 다니고 있다고 하며, 주양육자는 [모/부/조모]라고 보고하였음.`

### 검사태도 표현
- `보호자와 분리가 가능하였으며, 낯가림이 없는 편이었음.`
- `아동의 주된 의사표현 수단은 [gesture를 동반한 babbling / 문장표현]이었음.`
- `호명 시 [선택적으로 반응 / 비일관적인 반응]을 보였으나 [유의미한 / 의미있는] eye contact을 보임.`
- `행동 요구 시 주된 표현으로는 [crane, pointing, 물건 건네기]가 나타났음.`

### 결과 해석 표현
- `[검사명] 검사결과, [N-N)] [영역] 등가월령 [N]개월, 백분위수 [N]%ile로 평가됨. 또래와 비교하였을 때 -2SD미만에 해당하여 언어발달지체로 평가되었음.`
- `오반응 문항으로 [구체 예시 1, 2, 3] 등이 있었음.`
- `또래 아동들과 비교하였을 때 -2SD미만에 해당하여 [조음음운지연/언어발달지체]으로 평가됨.`
- `주된 오류 양상으로는 [마찰음의 파열음화], [파찰음의 파열음화]가 있었음.`

### 결론 표현
- `> [아동명](N;NN) 아동은 [주호소]을 주호소로 본 기관에 내원하였음.`
- `> 검사 결과, 아동은 [진단명(영문병기)]으로 판단됨.`
  - 언어발달지연 → `언어발달지연(Delayed language development)`
  - 조음음운장애 → `조음음운지연(Articulation and Phonological Disorders)`
  - 읽기부진 → `읽기부진(해독 및 읽기 유창성 저하-Reading difficulties with deficits in decoding and reading fluency)`
- `> [목표 영어용어(한글풀이)] 증진을 위한 주 N회 이상의 언어재활이 필요할 것으로 판단됨.`
  - 예: `> 초기의사소통의도(primitive speech acts)/대화 기능(conversational acts) 증진, 전반적인 수용 및 표현언어 증진을 위한 주 2회 이상의 언어재활이 필요할 것으로 판단됨.`
  - 예: `> Reading Fluency(읽기 유창성) 및 Phonological Automatization(음운 처리 자동화)를 위한 주 2회 이상의 언어재활이 필요할 것으로 판단됨.`
- `> 가정 내 효과적인 linguistic stimulus(언어자극) 제공을 위한 부모교육 또한 도움이 될 것으로 판단됨.`

### 감통(작업치료) 결론 표현
- `따라서 감각입력에 대한 올바른 처리와 적응반응 유도를 통해서 일상생활과 놀이상황에서 안정감을 느낄 수 있도록 할 필요가 있으므로 주 2회 이상의 감각통합치료가 권고됨.`
- `K-TSP2 평가결과로 사분면 중 [회피/회피자, 민감/민감자, 등록/방관자] 유형에서 '또래보다 매우 많음' 결과가 나타남.`

## 7. 전문용어 영한 병기 패턴

작성자는 **임상 영어용어 옆에 한글풀이를 괄호로 병기**한다.

| 영어용어 | 한글풀이 |
|---|---|
| gesture | 제스처 (영어로 사용) |
| babbling | 옹알이 (보통 영어 그대로) |
| jargon | 자곤 (영어 그대로) |
| crane | 손 끌어 요청 |
| pointing | 손가락 가리키기 |
| eye contact | 눈맞춤 |
| primitive speech acts | 초기의사소통의도 |
| conversational acts | 대화 기능 |
| linguistic stimulus | 언어자극 |
| Reading Fluency | 읽기 유창성 |
| Phonological Automatization | 음운 처리 자동화 |
| Delayed language development | 언어발달지연 |
| Articulation and Phonological Disorders | 조음음운지연 |

## 8. 표·숫자 표기 규칙

- **연령 표기**: `(22M)`, `(2y7m)`, `(4;02)`, `(7;06)`, `(9;08)` — 검사 종류와 양식에 따라 혼용
  - 영유아: `(22M)` 또는 `(2y7m)`
  - 학령전·학령기: `(4;02)` 형식 (세미콜론 + 두 자리)
- **백분위수**: `<1%ile`, `10-25%ile`, `40%ile`, `<10%ile`
- **표준편차**: `-2SD미만`, `-2SD 이하`
- **자음정확도**: `62.79%(또래평균: 94.16%)` 형식, 또래 평균 병기
- **개월수 차이**: `약 1M delayed`, `약 4M delayed`
- **K-DDST2 결과**: `의심스런 발달 -약 N세 N개월 수준`
- **K-DST 결과**: `또래 수준` / `추적검사 요망` / `심화평가 권고`
- **K-TSP2/K-CSP2 분류**: `또래와 유사` / `또래보다 많음` / `또래보다 매우 많음`

## 9. AI 생성 시 주의사항

1. **샘플의 줄바꿈·들여쓰기를 그대로 흉내내지 말 것** — 표는 마크다운/HTML 표로, 본문은 한 단락 → 빈 줄 → 다음 단락 구조로.
2. **숫자·날짜는 입력 데이터에서 그대로 가져오고 생성하지 말 것** — 평가일/생년월일/원점수는 사용자 입력 필수.
3. **진단명을 임의로 단정하지 말 것** — 검사 결과 수치에 근거해 표준 기준(-2SD 등)을 명시한 후 결론.
4. **권고 회기 수("주 N회")는 검사 결과의 심각도에 비례하여 제안**하되, 보통 `주 2회 이상`이 기본값.
5. **부모/보호자 보고와 검사 결과를 구분해 서술** — `보호자의 보고에 의하면...` / `검사 결과...` 두 출처를 섞지 말 것.
6. **장애 아동을 비하·낙인하는 표현 금지** — "문제가 있다", "낮다" 보다 "어려움을 보임", "지연 소견을 보임".

## 10. 진단명 매핑 치트시트 (검사결과 → 결론)

| 검사 결과 | 결론 진단명 |
|---|---|
| SELSI -2SD 미만 (영유아) | 언어발달지연(Delayed language development) |
| PRES -2SD 미만 또는 1M+ delayed | 언어발달지연 또는 언어발달지체 |
| REVT 정상 + U-TAP -2SD 미만 | 조음음운지연(Articulation and Phonological Disorders) |
| KOLRA 학년 평균 미도달 | 읽기부진(Reading difficulties with deficits in decoding and reading fluency) |
| LSSC 평균 + KOLRA 미도달 | 읽기 유창성 저하 및 읽기 학습 부진 |
| K-TSP2 사분면 1개+ "매우 많음" | 감각처리 어려움 / 감각방어 유형 (구체 유형 명시) |
| K-DDST2 의심스런 발달 다수 | 전반적 발달지연 의심 |
