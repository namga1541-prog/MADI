# 베타 출시 전 수동 테스트 체크리스트

> **목적**: 자동 검사(lint·smoke·sentinel)가 닿지 못하는 **로그인 후 실제 화면**을 대장님이 폰에서 직접 확인하는 최종 관문입니다.
> **방법**: 아래를 순서대로 누르며 "기대 결과"와 같은지 봅니다. 다르면 그 항목 번호를 알려 주십시오.
>
> **시작 전 필수**: 새 코드가 폰에 반영되도록 **강제 새로고침**(브라우저: 주소창 새로고침 길게→"강력 새로고침") 또는 **PWA 앱이면 완전 종료 후 재실행**. (안 하면 옛 코드가 떠서 정상도 비정상으로 보입니다 — PWA 캐시 함정)

---

## A. 이번 작업에서 바뀐 곳 (여기를 가장 꼼꼼히)

### A-1. 회원가입 버튼 → 도입 상담 우회
- [ ] 랜딩(첫 화면)에서 **"무료 체험 시작하기"** 또는 **"회원가입"** 류 버튼을 누른다
- **기대**: 가입 폼이 뜨지 않고, "가입은 센터 관리자를 통해 진행됩니다 📩" 토스트가 뜨며 메일 작성 화면으로 연결됨. 랜딩 화면이 깨지거나 멈추지 않음
- (계정 생성은 원장이 admin 화면 "직원추가"로만 — 의도된 동작)

### A-2. 로그인
- [ ] 관리자(원장/superadmin) 계정으로 로그인
- **기대**: 정상 로그인, 대시보드 진입

### A-3. 스케줄 — 주간 뷰 3개 모드 ⭐ (성능 리팩토링 핵심)
- [ ] 스케줄 탭 → **주간** 뷰
- [ ] **"👩‍⚕️ 치료사 기준"** 버튼 → 치료사별 행에 일정이 요일별로 정확히 표시
- [ ] **"👶 아동 기준"** 버튼 → 아동별 행으로 전환, 일정 정확
- [ ] **"🔴 중복 수업만"** 버튼 → 같은 날 2회 이상인 아동만 표시
- **기대**: 세 모드 모두 일정 칸의 **아동/치료사 이름·시간이 정확**하고, 모드 전환이 매끄러움 (빈 칸·잘못된 이름 없음)

### A-4. 스케줄 — 월간/일간 뷰
- [ ] **월간** 뷰 → 날짜별 일정에 아동 이름 정확
- [ ] **일간** 뷰 → 시간순 일정 정확
- **기대**: 아동 이름이 모두 올바름 (물음표 `?`나 빈 이름이 비정상적으로 많지 않음)

### A-5. 헤더 시계 "다음 일정"
- [ ] 화면 상단 시계 옆 표시를 확인 (오늘 일정이 있는 계정으로)
- **기대**: 오늘 남은 수업이 있으면 "⏱️ OOO N분 후" 또는 "📅 OOO HH:MM", 없으면 "아동 N명" 또는 "오늘 일정 없음". 시간이 지나도 다음 수업으로 갱신됨

### A-6. 선생님 권한 편집 (새로 연결된 기능) ⭐
- [ ] 관리자 설정/직원 관리 화면 → 다른 선생님 옆 **"권한"** 버튼
- [ ] 권한 모달이 열림 → 토글(예: AI 기능 사용) 끄고 **저장**
- **기대**: "✅ 권한 저장 완료" 토스트, 모달 닫힘. (그 선생님으로 로그인 시 해당 기능 차단되면 더 좋음 — 선택 확인)

### A-7. 직원 삭제
- [ ] 직원 목록에서 본인 아닌 계정 **삭제** → 확인
- **기대**: "🗑️ OOO 계정 삭제됨", 목록에서 사라짐

### A-8. AI 키 화면 (admin.html 센터 AI 키 관리)
- [ ] 관리자 센터(admin) → "센터 AI 키 관리" 카드
- **기대**: 키 **입력란·저장 버튼이 없고**, "✅ 마디 통합 키 운영 중 — 센터별 키 입력이 필요 없습니다" 안내만 표시

### A-9. AI 기능 1회 (중앙 통합 키 동작 확인) ⭐
- [ ] 아무 AI 기능 1개 실행 (IEP 생성 / 가정활동 추천 / 포트폴리오 / 부모 리포트 중 하나)
- **기대**: 정상적으로 생성됨 (별도 키 입력 없이 작동 — 중앙 키 사용 확인)

### A-10. AI 권한 차단 안내 (선택)
- [ ] (가능하면) AI 권한을 끈 선생님 계정으로 AI 기능 시도
- **기대**: "⚠️ AI 기능 사용 권한이 없습니다" 친절 안내 (403 에러 토스트가 아니라)

### A-11. 차트 표시
- [ ] 아동 상세 / IEP 화면의 **차트** 확인
- **기대**: 차트 정상 렌더. (로드 실패 시 "차트 로드에 실패했습니다…" 같은 친화 문구, 서버 원문/코드 노출 없음)

### A-12. 이미지 업로드 (upload-image fail-closed 확인)
- [ ] 게시판/포트폴리오에서 이미지 업로드
- **기대**: 정상 업로드. (연속으로 아주 많이 올리지 않는 한 막히지 않음)

### A-13. 푸시 테스트 (notify-test, admin)
- [ ] 관리자 알림 테스트 기능 실행
- **기대**: 테스트 푸시 정상 동작 (또는 "잠시 후 다시" 안내 — 정상)

---

## B. 핵심 흐름 (기존 안정성 재확인)

- [ ] **B-1** 위/아래 스크롤이 부드러움 (특히 안드로이드 — 스크롤 막힘 없음)
- [ ] **B-2** 세션 기록 작성 → 저장 → 목록에 반영
- [ ] **B-3** 아동 상세 화면 진입·정보 정확
- [ ] **B-4** ⚡ 빠른 기록 모드 (선생님) — 오늘 수업 카드 표시·저장
- [ ] **B-5** 마로(플로팅 버튼) 길게 눌러 이동
- [ ] **B-6** 로그아웃 → 랜딩으로 복귀

---

## C. 판정

- **모두 기대대로** → ✅ 베타 출시 가능
- **하나라도 다름** → 그 **항목 번호 + 무엇이 어떻게 달랐는지** 한 문장으로 알려 주십시오. (예: "A-3 아동 기준 모드에서 이름이 전부 물음표로 나옴")

> 참고: "안 된다"고 느끼면 먼저 **강제 새로고침/재설치 후에도 같은지** 확인해 주십시오 (PWA 캐시가 옛 코드를 띄우는 경우가 가장 흔한 원인).
