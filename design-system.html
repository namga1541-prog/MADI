🎨 MADI 디자인 시스템

토큰·컴포넌트 시각 검수용 페이지. 변경 후 이 페이지에서 일관성 확인 → 운영 적용.

1. 컬러 토큰

의미 기반(시맨틱) + 브랜드 팔레트. 신규 코드는 hex 직접 사용 금지.
mint#0ea5a0
mint2#e0f7f6
navy#0f2942
info#3b82f6
success#10b981
warning#f59e0b
danger#ef4444
text#1e293b
text2#64748b
bg#f4f8fb
브랜드 그라데이션 — var(--grad-brand) — 헤더·CTA 강조에 사용

2. 타이포그래피

5단계 본문 + 3단계 강조. 신규 코드는 px 직접 입력 금지, var(--fs-*) 사용.
--fs-3xl아이마디 28px
--fs-2xl페이지 제목 22px
--fs-xl섹션 제목 18px
--fs-lg인풋·강조 16px
--fs-md카드 제목 15px
--fs-base본문 텍스트 14px
--fs-sm라벨·캡션 12px
--fs-xs메타 정보 11px

3. Spacing (4px grid)

홀수 padding/margin 금지. 8단계 → 95% 케이스 커버.
12345678

4. Border Radius

--r-sm8px
--r-md12px
--r-lg16px
--r-xl20px
--r-full9999px

5. 버튼

한 페이지에 .btn-primary 는 1~2개만. .btn-del 은 진짜 위험할 때만.

6. 아이콘 (Lucide SVG)

이모지 금지. 모든 아이콘은 data-icon 또는 mdIcon() 으로.
<span data-icon="home" data-icon-size="20"></span>
mdIcon('calendar', 24, { stroke: 2 })

7. 모달

showConfirm / showInputPrompt 또는 .modal-overlay + .modal-card 구조.

8. 카드

기본 카드
정보 표시용. 좌측 강조선 없음.
브랜드 강조
핵심 액션·새 기능 안내
경고
주의 필요 상황·정체 알림

9. 빈 상태

텍스트만 X → 일러스트 + 제목 + 설명 + CTA.

10. 스켈레톤 로딩

스피너 대신 콘텐츠 위치에 placeholder. 사용자가 곧 나올 것을 예측 가능.
