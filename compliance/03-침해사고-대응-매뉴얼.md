# 침해사고 대응 매뉴얼 (Incident Response Playbook)

> 📌 **인쇄본 보관 필수** — 시스템 다운 시 디지털 매뉴얼 접근 불가
> 📌 **PIPA 통지 시한: 72시간** — 1000명 이상 영향 시 개인정보보호위원회 신고

## ⚡ 1단계 — 발견 (0시간)

### 발견 경로
- 외부 신고 (사용자·연구자) → 자동 알림
- 내부 모니터링 알람 (Supabase 콘솔·Anthropic 사용량 폭주)
- 정기 점검 중 발견
- 언론·SNS 노출

### 즉시 조치
- [ ] **사고대응팀(IRT) 소집** — 평일 30분 내 / 야간·휴일 1시간 내
- [ ] **사고 발견 시각 기록** — 시간 단위가 중요 (72시간 카운터)
- [ ] **증거 보존** — 로그·스크린샷·이메일 캡처 (덮어쓰기 금지)
- [ ] **외부 통신 모라토리엄** — 공식 발표 전 SNS·언론 대응 금지

## 🔍 2단계 — 분석·격리 (0~12시간)

### 영향 범위 파악
- [ ] 어떤 데이터가 영향받았는가? (PII / 민감정보 / 인증정보)
- [ ] 영향받은 사용자 수 — 대략 추정 → 정밀 추정
- [ ] 침투 경로 — 외부 공격 / 내부자 / 위탁사 / 운영 실수
- [ ] 데이터 유출 / 변조 / 파기 / 가용성 손실 중 어느 유형인가?

### 즉시 격리 조치 (체크리스트)
- [ ] **JWT 시크릿 회전** — Supabase Secrets → MADI_JWT_SECRET 갱신 → 전 사용자 자동 로그아웃
  ```
  새 시크릿 생성: openssl rand -hex 32
  Supabase Dashboard → Edge Functions → Secrets → MADI_JWT_SECRET 갱신
  ```
- [ ] **API 키 즉시 폐기** — Anthropic Console·Supabase 모두
- [ ] **공격 IP 차단** — Supabase 콘솔 또는 Cloudflare WAF
- [ ] **취약 함수 일시 중단** — Edge Function 삭제 또는 401 반환
- [ ] **백업 격리** — 침해 이전 시점 백업을 별도 보관

### 사용자 강제 로그아웃
```sql
-- 모든 사용자 강제 로그아웃 (SEC3 활용)
UPDATE madi_users SET session_revoked_at = now();
-- 또는 특정 의심 계정만
UPDATE madi_users SET session_revoked_at = now() WHERE id = '___';
```

## 📞 3단계 — 통지 (24~72시간)

### 정보주체 통지 (지체 없이, 통상 24시간 내)
- [ ] 영향받은 보호자·치료사·센터장 전체에게 이메일·SMS
- [ ] 통지 내용 (PIPA 시행령 제40조):
  - 유출된 개인정보 항목
  - 유출 시점·경위
  - 정보주체의 피해 최소화 방법
  - 사업자의 대응 조치
  - 담당부서·연락처

### 개인정보보호위원회 신고 (72시간 내, 의무)
**신고 기준**: 1000명 이상 정보주체 영향 또는 민감정보 누설
- 사이트: https://www.privacy.go.kr → 신고센터
- 신고서 양식: 개인정보보호법 시행규칙 별지 제3호
- 첨부: 사고 경위서, 피해 규모, 대응 조치

### KISA 한국인터넷진흥원 (해킹·랜섬웨어 시)
- 핫라인: 118
- 사이트: https://www.boho.or.kr

### 언론·고객 발표
- [ ] 보도자료 초안 (홍보·법무 검토 필수)
- [ ] 공식 사이트 공지 (privacy.html 또는 별도 페이지)
- [ ] FAQ 준비 — 고객 응대팀 대본

## 🎭 모의훈련 시나리오 (분기 1회)

### 시나리오 A — 외부 공격
공격자가 SQL Injection 으로 madi_children 전체 SELECT.
**훈련 목표**: 알람 → 격리 → 72시간 내 통지 절차 검증

### 시나리오 B — 내부자 위협
admin 권한자가 퇴직 후에도 자기 토큰으로 데이터 추출.
**훈련 목표**: session_revoked_at 즉시 적용 흐름 검증

### 시나리오 C — 위탁사 침해
Supabase 자체 침해 통보 → 영향 평가 → 사용자 통지
**훈련 목표**: DPA 의 24시간 통보 의무 작동 확인

### 시나리오 D — 랜섬웨어
백업 무결성·격리 검증 → 복구 시간 측정 (RTO)
