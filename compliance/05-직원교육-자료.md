- 2024 한국 의원 C사 — 직원이 USB 로 환자 1만명 정보 반출, 형사 입건

## 모듈 2 — 일상 보안 수칙 (15분)

### 2.1 계정 관리 — 매일 지킬 것

| ✅ DO | ❌ DON'T |
|-------|---------|
| 비밀번호 매니저 사용 (1Password·Bitwarden) | 비밀번호 메모지·메모장 저장 |
| 모든 계정에 다른 비밀번호 | 회사·사적 계정 같은 비번 |
| 2FA(2단계 인증) 활성화 | "귀찮으니 나중에" — 그 나중이 없다 |
| 노트북 자리 비울 때 화면 잠금(Win+L) | "잠깐 화장실인데 뭐" |

### 2.2 데이터 다루기 — 의식적으로

| ✅ DO | ❌ DON'T |
|-------|---------|
| 화면 캡처는 **꼭 필요할 때만**, 사용 후 즉시 삭제 | 카카오톡으로 화면 캡처 공유 |
| 외부에 보여줄 자료엔 **모자이크·가명** | "OO이 발음 70%" 같이 실명 그대로 |
| 회의 녹화는 동의 받은 후만 | 자동 녹화 + 클라우드 동기화 |
| USB·외장 디스크 사용 금지 | "잠깐 가져가서 집에서 작업" |

### 2.3 메일·메시지 — 가장 큰 침해 경로

#### 피싱 메일 식별법
- 발신자 도메인 확인 (`anthropic.com` vs `anthr0pic.com`)
- 첨부파일 — .pdf 가 .pdf.exe 일 수 있음
- "긴급" "확인 필요" "계정 잠김" 같은 조급함 유도
- 한국어가 어색하다 (번역기 흔적)

#### 의심되면?
1. **클릭 금지**
2. 발신자에게 다른 채널(전화)로 확인
3. IT 담당에게 신고
4. 메일 삭제 (단, 신고 후)

### 2.4 코드·시스템 접근 — 개발자용
- 본인 계정 외 다른 사람 계정으로 절대 로그인 금지
- 운영 DB 직접 쿼리 시 SELECT 만, UPDATE/DELETE 는 반드시 동료 확인
- API 키·시크릿을 코드에 하드코딩 금지 (이미 코드 리뷰에서 막힘)
- git 커밋에 PII 들어가지 않게 — `.gitignore` 활용

## 모듈 3 — 만 14세 미만 아동 처리 (10분)

### 3.1 법적 요건
- 「개인정보보호법 제22조의2」 — **법정대리인 동의 필수**
- 동의 없이 수집·이용·저장 시 형사 처벌 (5년 이하 징역)

### 3.2 우리 시스템에서
- 모든 아동 정보는 **보호자 동의서** 를 받은 후에만 입력
- 동의서 양식 — 회사 표준 양식 사용 (계약서와 함께)
- 동의 철회 시 **즉시** 처리 — 30일 이상 끌면 안 됨

### 3.3 동의 절차 체크
- [ ] 보호자 확인 (주민등록상 부모 또는 후견인)
- [ ] 수집 항목·목적·보유기간 명시
- [ ] 동의 거부 권리 안내
- [ ] 서명 또는 전자서명 수령
- [ ] 동의서 사본 보관 (5년)

## 모듈 5 — 한국언어재활사 윤리강령 연계 (10분)

### 5.1 임상가로서의 의무
- 비밀유지 의무 (협회 윤리강령 제5조)
- 정보 공유는 **치료 목적** 에 한정
- 다른 치료사와 사례 공유 시 — **가명** + 부모 동의

### 5.2 SNS·동료와의 대화
- "오늘 OO이가..." 식 대화 절대 금지 (식별 가능)
- 익명 사례라도 진단·연령·지역 조합으로 식별 가능
- 사회복지 단체·연구자 자료 제공 시 IRB 심의

### 5.3 부모와의 소통
- 진료실 외 카톡·문자 — 가능한 한 마디 학부모 포털로 일원화
- 사진 공유 — 학부모 동의 받은 사진만, 다른 아이 보이지 않게

**Q. 카카오톡으로 아동 사진 공유는?**
