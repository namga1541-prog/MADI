## 제1조 (목적)
본 계약은 위탁자가 위탁자가 보유한 개인정보의 처리를 수탁자에게 위탁함에 있어, 위탁자와 수탁자의 권리·의무를 정함을 목적으로 한다.

## 제2조 (위탁 업무의 내용)

### 2.1 위탁 업무
- [ ] 데이터베이스 호스팅 (Supabase: Postgres / Storage / Edge Functions)
- [ ] AI 추론 서비스 (Anthropic: Claude API)
- [ ] 정적 사이트 호스팅 (GitHub: Pages)
- [ ] 이메일 발송 (예: SendGrid, Mailgun)
- [ ] 푸시 알림 (Web Push, FCM, APNs)
- [ ] 결제 처리 (예: 토스페이먼츠)
- [ ] 기타: ____________

## 제3조 (보안 조치 의무)

수탁자는 다음의 보안 조치를 이행한다:

### 3.1 기술적 조치
- 전송 구간 암호화 (TLS 1.2 이상)
- 저장 시 암호화 (AES-256 동등)
- 접근 권한 분리 (역할 기반)
- 비정상 접근 탐지 로깅
- DDoS / WAF 방어

### 3.2 관리적 조치
- 개인정보 처리 담당자 지정 및 위탁자에 통보
- 임직원 비밀유지서약서 수령
- 분기 1회 이상 보안 교육 실시
- 보안 인증 보유 (SOC 2 / ISO 27001 / K-ISMS 등) — 첨부

### 3.3 물리적 조치
- 데이터센터 보안 (CCTV, 출입통제)
- 백업 매체 암호화 및 격리 보관

## 제4조 (재위탁 금지)
수탁자는 본 계약상 업무를 제3자에게 재위탁할 수 없다. 단, 다음의 경우는 예외로 한다:
1. 위탁자의 사전 서면 동의를 받은 경우
2. 본 계약과 동등 이상의 의무를 재수탁자가 부담하는 경우

## 제5조 (개인정보 이전·국외처리)

### 5.1 국외 이전 가능 국가
- [ ] 미국 (Supabase, Anthropic)
- [ ] 유럽 (GitHub, Cloudflare 등)
- [ ] 기타: ____

### 5.2 이전 근거
- [ ] 정보주체의 동의 (privacy.html 명시 + 동의서 수령)
- [ ] 계약 이행에 필수 (서비스 제공 불가능)

## 제6조 (위탁자 권리)

### 6.1 감사권
위탁자는 분기 1회까지 수탁자의 개인정보 처리 현황을 점검할 수 있다.

### 6.2 즉시 통보 의무
수탁자는 다음의 경우 위탁자에게 **24시간 이내** 통보:
- 침해사고 발생·감지
- 권한 있는 기관의 자료 요청
- 보안 인증 변경·취소
- 핵심 인력 교체

## 제7조 (계약 종료 시 의무)

계약 종료 또는 위탁업무 완료 시 수탁자는:
1. 보유한 모든 개인정보를 위탁자에게 **반환** 또는 **파기**
2. 파기 시 복구 불가능한 방법 사용 (NIST SP 800-88 동등)
3. 파기 완료 보고서를 위탁자에게 제출 (30일 이내)

## 제8조 (손해배상)
수탁자의 귀책으로 발생한 개인정보 침해 사고에 대해 수탁자는 위탁자가 입은 손해를 배상한다.
(사이버 보험 가입 의무 — 보험증서 첨부)

## 제9조 (정보주체 권리행사 협조)
정보주체로부터 열람·정정·삭제·처리정지 요청이 위탁자에게 접수된 경우, 수탁자는 위탁자의 요청에 따라 지체 없이(영업일 5일 이내) 협조한다.

## 제10조 (분쟁 해결)
본 계약과 관련한 분쟁은 (서울중앙지방법원/서울중앙지방법원) 을 1심 관할 법원으로 한다.
국외 수탁자의 경우 [ICC 중재 / 서울국제중재센터] 를 따른다.
