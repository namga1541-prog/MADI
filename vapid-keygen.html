MADI VAPID 키 생성기

Web Push 알림에 필요한 VAPID 키를 1회 생성합니다.

⚠️ 이 페이지를 닫으면 키를 다시 볼 수 없습니다. 아래 값을 모두 복사해두세요.
① VAPID 공개키 (VAPID_PUBLIC_KEY)
Supabase 시크릿 + madi-parent-home.js MADI_VAPID_PUBLIC_KEY 변수에 입력
② VAPID 비공개키 (VAPID_PRIVATE_KEY)
Supabase 시크릿에만 입력 — 절대 공유 금지
③ Supabase CLI 명령어 (한 번에 설정)
터미널에서 실행하면 세 가지 시크릿이 한 번에 등록됩니다.
📋 다음 단계
1. 위 CLI 명령어를 터미널에서 실행 → Supabase 시크릿 등록
2. madi-parent-home.js 파일 상단의 MADI_VAPID_PUBLIC_KEY 변수에 공개키 붙여넣기
3. notify-tomorrow Edge Function 배포
4. Supabase Dashboard > Edge Functions > notify-tomorrow > Schedule 에서
   Cron 표현식 */10 * * * * 으로 설정
