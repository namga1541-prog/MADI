## 🍎 Apple Developer Program

| 항목 | 값 | 비고 |
|------|------|------|
| 등록 비용 | $99/년 | 매년 자동 갱신 |
| 개발자 계정 유형 | Individual / Organization | Org 선택 시 D-U-N-S 번호·법인 등기 필요 |
| 발급 기간 | Individual 1~2일, Org 1~2주 | Org 는 Apple 전화 인증 (영어) |
| Apple ID | 별도 새로 만들 것 (개인용 분리 권장) | 2단계 인증 필수 |
| Bundle ID 예시 | `kr.madi.app` 또는 `com.madi.app` | 한 번 정하면 변경 불가 |
| App Store Connect 팀 이름 | 사업자명 또는 "MADI" | 사용자에게 공개 |

### Apple 의 "Trade Name" 표시
- **개인 계정**: 본명이 그대로 노출됨 (예: "남재현")
- **법인 계정**: 사업자명 노출 (예: "주식회사 아이마디")
- 본명 노출이 부담되면 법인화 전까지 출시 보류 권장

### Sign in with Apple (필수 조건부)
- 다른 소셜 로그인을 제공하면 반드시 Sign in with Apple 도 제공
- **현재 마디는 자체 username/password 만 → 면제**
