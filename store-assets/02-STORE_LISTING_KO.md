## 전체 설명 (Full Description, 4000자 제한)

```
🌱 아이마디 (MADI) — 언어치료 통합 관리 앱

언어재활 치료사 한 명이 처리하는 일은
세션 기록, 평가, IEP, 보고서, 학부모 소통, 일정 관리…
하루 24시간이 모자랍니다.

아이마디는 이 모든 업무를 한 앱에서, AI가 거들어 처리합니다.
선생님은 아이와 더 깊이 마주할 수 있게 됩니다.

• 1:1 또는 그룹 치료를 진행하는 언어재활사·치료사
• 자녀의 치료 경과를 가정에서도 확인하고 싶은 학부모

✨ 핵심 기능

📝 빠른 세션 기록
• 음성 받아쓰기 → 임상 어휘로 자동 정리
• 사진 첨부, 다음 회기 메모, 평가 점수 한 화면
• 한 회기 기록까지 평균 1~2분

🤖 AI 임상 보고서
• 표준화 검사 결과 → 임상 수준 평가 보고서 자동 생성

• 출결·종결·휴원 한 번에 처리

🌙 다크모드 · PWA 설치
• 홈 화면에 설치해 네이티브 앱처럼 사용
• 오프라인 일부 기능 지원
• Wi-Fi 없어도 빠른 기록은 가능
```
